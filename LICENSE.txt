WHAT THE MIT LICENSE ABOVE COVERS - AND WHAT IT DOES NOT

It covers the source code in this repository.

It does NOT cover a COMPILED BINARY of this firmware. The build links against
ElegantOTA, which is licensed under AGPL-3.0 (details further down). Linking
makes the result a combined work, so a binary you pass on - a release asset, or
a device sold with the firmware already flashed - carries the AGPL-3.0 terms
rather than MIT. Put plainly: the source in this repository is MIT, a binary
built from it is effectively AGPL-3.0.

For personal use this changes nothing, and AGPL-3.0 does not forbid selling
anything. What it does require of anyone distributing a binary:

- The recipient must be able to obtain the complete corresponding source under
  AGPL-3.0 - everything needed to rebuild that exact binary.
- Because this firmware serves a web interface over the network, people who use
  it over a network must be offered that source as well (AGPL-3.0 section 13).
- Modified versions must stay under AGPL-3.0.

If you want a build that really is MIT and nothing else, replace ElegantOTA
with the Update library from the ESP32 core. The project already runs its own
web server, so it is a small change.

MAP DATA

Map data (MeteoPlaneRadar/EuMapData.h and MeteoPlaneRadar/CzCitiesData.h) is
derived from:

- Natural Earth (https://www.naturalearthdata.com/) - country borders, 1:10m.
  Public domain. Obtained via the world-atlas TopoJSON redistribution
  (https://github.com/topojson/world-atlas), which is ISC licensed.

- GeoNames (https://www.geonames.org/) - city locations and population.
  Licensed under Creative Commons Attribution 4.0 (CC BY 4.0):
  https://creativecommons.org/licenses/by/4.0/

  ATTRIBUTION REQUIRED: if you redistribute this project or a derivative,
  you must credit GeoNames. The notice above satisfies this.

DATA SOURCES USED AT RUNTIME

The software fetches data from the following services. None of them are
redistributed with this repository, but each has its own terms, and several
require attribution. Please review them before any commercial deployment.

- adsb.fi (https://adsb.fi/) - aircraft positions.
  Free, no API key. Intended for personal, non-commercial use.
  Commercial products should arrange appropriate data access.

- adsbdb.com (https://www.adsbdb.com/) - flight route, registration and
  aircraft type. Free, no registration.

- CHMI / Cesky hydrometeorologicky ustav (https://opendata.chmi.cz/) -
  precipitation radar composite for the Czech Republic.
  ATTRIBUTION REQUIRED: the source must be credited when the data is used.

- RainViewer (https://www.rainviewer.com/) - international precipitation radar.
  Free, no API key, for personal, educational and small-scale community use.
  ATTRIBUTION REQUIRED: RainViewer requires visible credit with a link back to
  https://www.rainviewer.com/. Commercial use is arranged case by case.

- Open-Meteo (https://open-meteo.com/) - current weather, forecast, sunrise and
  sunset, air quality, pollen and city geocoding.
  The free API is for NON-COMMERCIAL USE ONLY and the data is provided under
  CC BY 4.0, so ATTRIBUTION IS REQUIRED. Rate limits apply (10,000 calls per
  day, 5,000 per hour, 600 per minute). Commercial use requires a paid plan:
  https://open-meteo.com/en/pricing

- ip-api.com (https://ip-api.com/) - approximate location from the IP address.
  The free endpoint is for non-commercial use.

Note on attribution: the settings screen and this file credit the sources
above. If you build a derivative with a different user interface, make sure the
required credits (GeoNames, CHMI, RainViewer, Open-Meteo) remain visible
somewhere the user can find them.
